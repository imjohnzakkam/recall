# Supermemory Local Hackathon brief

Recall demonstrates that local memory can turn terminal history into reusable operational
knowledge. The demo has three beats: a keyword-disjoint semantic match, the exact commands
that fixed the earlier incident, and offline operation with redaction before ingestion.

The core differentiator is failure-to-success resolution linking: Recall remembers the fix,
not merely the failure. Local execution is load-bearing because terminal output is private,
high-volume, and expected to remain useful without network access.

Build window: July 9–13, 2026. The seeded corpus exists only to make the presentation
deterministic; real usage learns from captured failures and later successful reruns.
